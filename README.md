# 🌌 NEON ETERNITY: P2P MMO

**Neon Eternity** est un MMO 3D décentralisé révolutionnaire conçu pour une expérience mobile-first. Sans serveur central, le monde est maintenu par ses joueurs grâce à la technologie Gun.js.

## 🚀 Caractéristiques "GOTY"
- **Architecture Zero-Server** : Synchronisation P2P via Gun.js.
- **Rendu AAA** : Moteur Three.js avec post-processing UnrealBloom et shaders néon.
- **Gameplay Vertical** : "Tower of God" avec inversion de gravité et dash.
- **Monde Persistant** : Chaque action est synchronisée en temps réel sur le graphe décentralisé.
- **Sécurité Crypto** : Authentification SEA (Security, Encryption, Authorization) sans base de données centrale.

## 🎮 Commandes (Mobile & Desktop)
- **Joystick Virtuel** : Déplacement (Gauche de l'écran).
- **Double Toucher** : Inversion de la Gravité.
- **Chat** : Communiquez instantanément avec tous les joueurs connectés.

## 🛠️ Stack Technique
- **Three.js** : Moteur 3D et Shaders.
- **Gun.js** : Base de données décentralisée et synchronisation P2P.
- **Nipple.js** : Interface de contrôle tactile.
- **Glassmorphism UI** : Interface moderne et immersive.
